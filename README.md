# Сборник лабораторных работ по алгоритмам и структурам данных

Данный репозиторий содержит программные реализации и отчеты по ключевым алгоритмам и структурам данных, изученным в рамках учебного курса. Работы охватывают темы от классических сортировок до сложных графовых задач и теории вычислений.

## Содержание репозитория

### 1. Алгоритмы сортировки и структуры данных
*   **Шейкерная сортировка (Cocktail Shaker Sort):** Реализация двунаправленной модификации пузырьковой сортировки для оптимизации перемещения элементов в обе стороны.
*   **Сортировка Шелла (Shell Sort):** Обобщение сортировки вставками с использованием адаптивного шага (gap), значительно ускоряющее процесс на больших массивах.
*   **Префиксное дерево (Trie / Бор):** Реализация древовидной структуры для эффективного хранения словаря и быстрого поиска слов по их префиксам.

### 2. Графовые алгоритмы: Кратчайшие пути
*   **Алгоритм Дейкстры:** Нахождение кратчайших путей в графах с неотрицательными весами ребер.
*   **Алгоритм Беллмана-Форда (Динамическое программирование):** Поиск оптимальных путей в графах, в том числе с возможностью обработки отрицательных весов.

### 3. Графовые алгоритмы: Минимальное остовное дерево (MST)
Сравнительная реализация двух классических «жадных» подходов:
*   **Алгоритм Краскала:** Использование системы непересекающихся множеств (**DSU**) для объединения компонентов связности на основе отсортированных ребер.
*   **Алгоритм Прима:** Постепенное расширение остова от стартовой вершины с использованием приоритетной очереди для выбора минимального инцидентного ребра.

### 4. Комбинаторная оптимизация
*   **Задача коммивояжера (TSP):** Решение классической задачи обхода всех городов методом **«Ветвей и границ»**.
    *   Работа с матрицами смежности.
    *   Построение дерева решений и отсечение неперспективных маршрутов.

### 5. Теория вычислений
*   **Машина Тьюринга:** Эмуляция работы детерминированного вычислительного устройства.
    *   Разработан алгоритм побитового дополнения двоичной строки.
    *   Реализовано управление лентой и сменой внутренних состояний автомата.

## Ключевые результаты

1.  **Анализ сложности:** Для каждого алгоритма проведено исследование временной и пространственной сложности ($O(E \log V)$, $O(n^2)$ и др.).
2.  **Эффективность:** Продемонстрировано преимущество использования специализированных структур данных (Trie, DSU) для ускорения поиска и группировки.
3.  **Оптимальность:** Найденные решения задач TSP и MST подтверждены на контрольных тестах как минимально возможные по стоимости.
